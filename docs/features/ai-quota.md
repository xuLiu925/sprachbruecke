# AI 次数（免费用户和会员）

## 功能介绍

AI 生成的内容（句子讲解、AI 查词、构词解释、词性联想记忆、替换练习、AI 生成对话）对所有人都一样，按句子或按词保存，第一次生成后大家共用。区别在能用多少：

| 功能 | 免费用户 | 会员 |
|---|---|---|
| 句子讲解 | 每次打开算 1 次 AI 次数（同一句当天再看不算） | 不限 |
| AI 查词、构词解释、词性联想记忆 | 已经生成过的随便看；新生成算 1 次 | 不限 |
| 替换练习 | 不能用（会员功能） | 不限 |
| AI 生成自建对话 | 不能用（会员功能） | 每天 3 次 |
| 重新生成、换一个、AI 出题、释义草稿 | 管理员专用 | 管理员专用 |

- 免费用户每天 **5 次** AI，上面几样共用。用完时弹出会员弹窗；「我的」页的今日用量里也能看到。
- 会员和免费用户每人每天最多**新生成 200 条**，防止有人刷 API 费用；看已经生成好的内容不受这个限制。管理员都不限。
- 试学的 10 个词，游客和免费用户看讲解、构词都不算次数。

## 详细设计

后端在 `billing.py`：

- `AI_FREE = 5`、`AI_GEN_CAP = 200`、`CUSTOM_PER_DAY = 3`。
- 记录在 `usage_daily`（和练习次数同一张表，按用户本地日期）：免费用户每用一样东西记一行 `ai:键`（如 `note:句子编号`、`dict:词`、`parts:词`、`memo:冠词:词`、`drill:句子编号`），今天 `ai:%` 的行数就是今天用了几次，同一样东西再用不增加行数；新生成一次 `aigen` 加 1；自建对话 `customgen` 加 1。
- `ai_block(uid, key, generate)`：用之前查，能用返回 None，否则返回 402（免费次数用完，带 `paywall`）或 429（今天生成太多）。`ai_done(uid, key, generated)`：成功后才记，失败不扣次数。`member_only(uid, 名字)`：会员功能，免费用户返回 402，带 `title: 这是会员功能`。
- `ai_can_generate(uid)`：接口返回的 `gen`，前端据此决定显示“生成”按钮还是“还没有”。免费用户次数用完也返回 true，点了再弹会员弹窗。

各接口：

- `GET /api/explain`：有讲解时免费用户算一次（试学例句不算）；返回多了 `gen`。`can` 仍然是“管理员”，用来显示重新生成和粘贴免费 AI 的入口。
- `POST /api/explain/generate`、`/api/dict/ai`、`/api/parts/generate`、`/api/gender_memo`：原来只有管理员，现在登录用户都能调，按上面的规则查次数。`again`（重新生成 / 换一个）仍然只有管理员。
- `GET /api/drills`、`POST /api/drills/generate`：会员功能。
- `POST /api/custom_lessons/generate`：会员功能，会员每天 3 次；`GET /api/custom_lessons` 多了 `member`。粘贴免费 AI 结果的 `/prompt`、`/check` 没变，所有登录用户都能用（不花我们的钱）。

前端：`static/js/core.js` 的会员弹窗支持后端给的标题（`#payTitle`）；`explain.js`、`parts.js`、`core.js`（联想记忆）、`search.js`、`words.js`、`lessons.js`（AI 查词）改看 `gen`；非管理员生成失败时只显示错误，不显示“复制提示词”；`lessonnew.js` 免费用户的按钮写“AI 生成对话（会员功能）”。

### 防投毒：提示词只用服务器自己的数据

讲解、替换练习、AI 查词、构词、联想记忆的结果按句子 / 词保存，**所有人共用**。如果提示词里有前端传来的文字，有人就能在里面写“讲解里加上某某网址”，AI 照做后存下来，之后所有人看到的都是被改过的内容。所以（`ai_inputs.py`）：

- 讲解、替换练习的中文翻译：只用自带课文（每行和写作参考答案）和公共词库例句（`words.example` 第二行）里的翻译；别的句子（自建对话、自己写的例句、程序拼出来的题）不带翻译，让 AI 自己理解。
- AI 查词的原句：只有自带课文或公共例句里、而且含这个词的句子才带上。
- 构词、联想记忆的释义：用公共词库 > 德语词典里的释义，没有就不给。联想记忆的冠词和词库 / 词典对不上时不生成。
- 前端照旧传 `zh` / `meaning` / `context`，后端不再使用（只有管理员的复制提示词、重新生成还用）。
- 管理员重新生成时提示词里有用户的报错内容；管理员在列表里能先看到报错再决定，所以没改。

## 费用估算

模型默认 `gemini-3.5-flash-lite`。第三方价格汇总（没直接看到 Google 的价格页，以 https://ai.google.dev/gemini-api/docs/pricing 为准）：输入 0.30 美元 / 百万 token，输出 2.50 美元 / 百万 token。一条讲解大约输入 600、输出 800 token，约 0.002 美元（约 1.6 分人民币）；一段自建对话约 0.007 美元。每月新生成 1000 条讲解约 2 美元。一个人每天刷满 200 条约 0.44 美元。

**开放给用户前要换成付费的 Gemini API Key**：免费档条款不允许向 EEA 用户提供服务。
