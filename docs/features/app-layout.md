# 页面结构和界面风格（新版）

## 功能介绍

底部四个标签按“用户想干什么”分：

- **今天**：日期和连续学习天数；深蓝大卡片里是今日进度环、还要复习几个 / 新词几个、一个主按钮（开始 / 继续今天的学习，学完了是“再学 10 个”）；**推荐练习**（有冠词、复数、动词错题或到期的整句复习时才出现，点了直接去练）；**这一周**每天学了多少个词的柱状图。会员快到期的提醒还在原来的位置。
- **学习**：查词入口（打开全局搜索）；当前单词书（已掌握 / 学习中 / 没学的进度条，换一本、全部单词、添加单词）；语法知识点按 12 个大类排成格子（点了进语法基础并跳到那一类）；情景课和新建工作对话；发音规律（即将推出）。
- **练习**：最上面是错题本汇总（冠词、复数、动词的错题数，点了去对应的练习）；下面按能力分组：名词（定冠词、不定冠词、kein、物主冠词、复数、变格、冠词快速选择）、动词（现在时、完成时、搭配、变位表）、句子、听说（听写、整句复习）。有错题或到期的项目右边有橙色标记。
- **我的**：内容不变（第二阶段再改样子）。

原来的“词库”标签变成“学习 → 全部单词”。

界面风格：主色深蓝 `#1f4e78`（和桌面图标一致），暖橙只用在连续天数、到期 / 错题标记、提醒；der / die / das 继续蓝红绿，图标块用同色浅底；线条图标代替 emoji（新页面），每屏一个深色主按钮；卡片圆角 18。字体用设备自带的（苹方 / 思源黑体 / 微软雅黑），德语和数字优先 Inter / 系统西文字体，**不从谷歌加载**（国内打不开，会卡住页面）。

## 详细设计

| 文件 | 作用 |
|---|---|
| `static/index.html` | 底部标签栏 `home / learn / practice / me`；`home`（今天）、`learn`、`practice` 三个 section 重写 |
| `static/js/core.js` | `PAGES`：`learn` 是标签页，`words` 改成二级页（`parent: learn`），语法、情景课、单词书的上一级是 `learn`，句子练习的上一级是 `practice`；标签页给 `body` 加 `tabpage`（顶栏透明、不显示标题，页面里有大标题） |
| `static/js/home.js` | `listItem(tile, …)`：`tile` 可以是 `{text, cls}`（文字图标块，`cls` = der/die/das/gray）或 `{svg}`，旧页面传 emoji 字符串照旧；`openTopic(id)`、`openForms(kind)`；`onShow.home`（进度环、`showWeek`、`showRecommend`）、`onShow.learn`（`buildGrammarGrid`，`GROUP_EXAMPLES` 是每类语法的德语小例子）、`PRACTICE_GROUPS` + `onShow.practice` |
| `static/js/grammar.js` | `gJumpGroup`：从学习页点某一类，语法基础滚到那一类的标题 |
| `today.py` | `/api/today` 多 `streak`（连续天数，今天没学时算到昨天）和 `week`（最近 7 天每天学的词数，最早 → 今天），从 `review_log` 按本地日期算（凌晨 4 点换日，最多往回 60 天） |
| `static/app.css` | 新的颜色变量（`--warm*`、`--der-soft` 等，深色模式各有一套）、`--font` / `--font-latin`；`.ptitle .phead .shead .hero .ring .streak .week .tile44 .tile36 .ggrid .gcell .searchbox .bookcover .bar3 .wrong3`；列表、按钮、卡片、标签栏的新样式 |

推荐练习和练习页的错题数来自 `/api/grammar/nouns/books`、`/api/plural/books`、`/api/grammar/verbs/books` 的 `wrong`，整句复习来自 `/api/roleplay/due?count=1`；哪个查失败就不显示那一项。
