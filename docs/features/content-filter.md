# 敏感内容过滤

## 功能介绍

通德是语言学习应用，不讨论政治、宗教，也不要色情、暴力、辱骂、歧视的内容。批评和吹捧两个方向的政治内容都不要。

- **AI 不写这些内容**：所有 AI 提示词里都写了这条规则。用户在新建情景对话里要求写这类场景时，AI 拒绝，页面提示“这个场景不适合做成课文，换一个场景吧”。
- **关键词兜底**：用户名、意见反馈、新建情景对话（描述、AI 生成的结果、粘贴回来的结果、保存）里出现敏感词，就不保存，提示换一种说法。
- **共用的 AI 内容**：讲解、替换练习、AI 查词、构词、联想记忆的结果里，如果 AI 自己加进了敏感词，就不保存。单词书里本来就有的词（如 Diktator 独裁者、Vergewaltigung 强奸）讲解它们不算。

## 详细设计

### 涉及的文件

| 文件 | 作用 |
|---|---|
| `content_filter.py` | `SAFETY_RULE`（提示词里的规则）、`DEFAULT_WORDS`（基础词表）、`blocked()`、`added()` |
| `.blocked_words`（服务器上，不进版本库） | 额外的词，一行一个，`#` 开头是注释；改了自动生效，不用重启 |
| `custom_lessons.py` | 描述（`read_request`）和课程内容（`clean_lesson`，生成、粘贴、保存都走它）都查；AI 返回 `{"refused": true}` 时提示换场景 |
| `explain.py`、`dictionary.py`、`word_parts.py`、`gender_hint.py` | 提示词加 `SAFETY_RULE`；保存前用 `added()` 查 AI 结果 |
| `grammar.py` | 管理员 AI 出题的提示词加 `SAFETY_RULE`（只有管理员能保存，不查关键词） |
| `auth.py`、`feedback.py` | 用户名、意见反馈 |

### 怎么匹配

- **中文词**：去掉空格和标点后按字串找，所以“习 近 平”也能拦住。中文不分词，太短的词会误伤（“其中共有”里有“中共”、“出口交易”里有“口交”、“舞台独唱”里有“台独”），所以词表里只放不会和正常话连在一起的词，比如“台湾独立”而不是“台独”。
- **英文 / 德文 / 拼音**：只按整个词找，不然 `Haus extra` 连起来会找到 `sex`。词组写成 `xi jinping`、`heil hitler`。
- 每段文字分开查，不会把两个字段连起来误判。
- 自带的 15 节课全部不会被拦（2026-11-05 检查过）。

### 已知限制

- 关键词只能挡随手写的，拼音缩写、谐音、拆字挡不住；主要靠 AI 规则。
- 词别加太宽（如“中国”“政府”“共产主义”），正常课文和例句会被误伤。
- 单词书里本来就有一些敏感词条和例句（强奸、独裁者、Nigger 等，约 20 个），是词典内容，没有删；要不要从单词书里去掉由用户决定。
- 用户自己加的词、改的释义只对自己可见，没有过滤。
