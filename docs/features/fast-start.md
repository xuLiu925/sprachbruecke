# 打开更快：启动画面和静态文件缓存

## 功能介绍

以前点开软件，加载时整页是白的。现在：

- **启动画面**：网页一到就显示蓝底的启动画面（图标、“通德”、转圈），页面准备好后淡出。颜色和装到桌面时的启动色一样，从桌面图标打开时接得上。
- **第二次打开更快**：页面用到的 20 多个脚本和样式文件会存在浏览器里，下次打开不用再一个个向服务器确认。发布新版后浏览器会自动换成新文件，不用清缓存。

安卓 App 的原生启动背景还是白色，要等下次打包 APK 时改成蓝色（见 CLAUDE.md 第 67 项）。

## 详细设计

- 启动画面写在 `static/index.html` 开头的 `#splash` 里，样式也写在这里，不用等 `app.css` 下载完。CSP 允许内联样式，不允许内联脚本，所以隐藏逻辑放在 `core.js` 的 `hideSplash()`，由 `showApp()` 调用（`boot()` 问完 `/api/me` 后总会走到这里）。深色模式用 `#0f1b26`。
- 静态文件缓存在 `app.py`：
  - 首页 `/` 不再直接发送文件，而是由 `versioned_index()` 把 `index.html` 里的 `static/….js` 和 `static/….css` 换成 `static/….js?v=指纹`。指纹是文件内容 md5 的前 10 位，按文件修改时间缓存，文件没变就不重算。
  - 带 `?v=` 的 `/static/` 请求返回 `Cache-Control: public, max-age=31536000, immutable`；首页本身是 `no-cache`，每次都会向服务器确认。文件内容一变指纹就变，网址也跟着变，所以不会用到旧文件。
  - 不带 `?v=` 的静态文件（图标、manifest、`sw.js`、APK）还是原来的方式。
- 以后在 `index.html` 里新加 `<script src="static/js/xxx.js">` 或样式表，会自动带上指纹，不用另外处理。
