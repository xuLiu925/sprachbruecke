# 全局搜索

## 功能介绍

任何页面都能查词，不用先进“词库”页。

- **打开：** 点顶栏右上角的放大镜，电脑上也可以按 `/`。
- **搜索：** 输入德语、变化形式（`ging`）或中文，边输入边显示结果。
- **看结果：** 点一个词，打开底部单词卡，详情默认展开。关掉卡片后回到搜索结果，再关掉搜索就回到原来的页面。
- **最近查过：** 没输入内容时显示最近点开的 10 个词，存在本机。
- **关闭：** 点“取消”、结果下方的空白处、按 Esc 或手机返回键。
- **查不到时：** 管理员可以点“用 AI 查询”。
- **没学过的词：** 卡片上有“加入学习”。

### 做题时不能搜索

搜索能直接看到答案，所以答题时放大镜不显示，`/` 也不起作用，答完才恢复。

包括今日学习、冠词练习、听写、句子练习（也包括词形练习、复数练习和情景课的填空）、语法练习、角色扮演。

## 详细设计

### 涉及的文件

| 文件 | 内容 |
|---|---|
| `static/js/search.js` | 打开关闭、答题时隐藏、搜索、最近查过 |
| `static/js/words.js` | `wordRow()`：词库和搜索共用的一行 |
| `static/js/lessons.js` | `openWordId()` 按学习状态决定显示“加入学习” |
| `static/js/core.js` | 快捷键；设置 `recentSearch` |
| `static/index.html`、`static/app.css` | 放大镜按钮和搜索层 |

没有新接口和新表，搜索用现有的 `/api/dict`，AI 查词用现有的 `/api/dict/ai`。

### 关键取舍

- **用按钮，不用手势：** 下拉和浏览器的下拉刷新冲突，做题时刷新会丢掉这一组题；左右滑和返回手势冲突；上滑和页面滚动冲突。手势也看不见。
- **答题状态怎么判断：** `SEARCH_LOCKS` 给每个练习页写两个区域，题目区显示着而答案区没出现就是在答题。用 `MutationObserver` 监听 `main` 里的 class 变化，不用改每个练习页。新增练习页时要在这里登记。
- **返回键：** 打开搜索时 `history.pushState` 加一条历史，`popstate` 和 `hashchange` 都按 `history.state.search` 决定显示不显示。这样返回键能关闭搜索；从单词卡进详情页再返回时，搜索结果还在。
- **不离开当前页面：** 结果用底部单词卡显示。（2026-11-09 起练习页去详情页再返回会接着做原来那一题，见 `quiz-resume.md`。）

### 已知限制

- 最近查过存在浏览器里，同一设备换账号登录时还看得到。
- 查词结果最多 50 条，来自 `/api/dict` 的限制。
