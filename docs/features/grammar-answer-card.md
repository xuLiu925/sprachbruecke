# 语法题答案查词

## 功能介绍

语法基础的选择题答完后，答案会填到横线上。这个答案和句子里的其他词一样，可以点开底部单词卡。

不定冠词、否定冠词、物主冠词的答案，点开后显示原形的单词卡，顶部写明这个词形是怎么来的：

| 答案 | 单词卡 | 说明 |
|---|---|---|
| `meinen` | `mein` | 物主冠词：我的（mein + 词尾 -en） |
| `seinen` | `sein` | 物主冠词：他的（sein + 词尾 -en） |
| `eurem` | `euer` | 物主冠词：你们的（euer + 词尾 -em，去掉中间的 e） |
| `ein` | `ein` | 不定冠词：ein，没有词尾 |

答题前横线是空的，不能点。选整句的题（如看回答选问句）没有横线，答案不能点。

## 详细设计

### 涉及的文件

| 文件 | 内容 |
|---|---|
| `article_quiz.py` | `answer_note()` 生成说明；题目多 `answer_lemma` 和 `answer_note` |
| `static/js/grammar.js` | `promptInto(el, q, answered)` 把答案渲染成可点的词 |
| `static/js/lessons.js` | `openWordSheet()` 显示 `line.notes` 里的说明 |

没有新接口和新表。`/api/grammar/articles` 的题目多两个字段。

### 为什么要带原形

点词是按词形查词库，物主冠词的变化形式查不准：`meinen` 会查到动词“认为”，`deinen` 这类词反查不到，因为去词尾只对形容词生效。

所以题目带上原形，前端放进 `line.map`，`openWordSheet()` 先用它查词。这个映射只属于这道题的答案，课文里的 `meinen` 还是动词。

说明放进 `line.notes`，这样从下一张卡返回时也还在。

### 已知限制

- 词库里 `sein` 只有动词词条，所以“他的 seinen”打开的卡片释义是“是，在”，要靠顶部说明区分。
- 其他语法题的答案没有带原形，还是按词形查，可能查到别的词或查不到。
