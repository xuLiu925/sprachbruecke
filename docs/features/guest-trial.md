# 不登录先试用（游客试学）

## 功能介绍

- 打开网站先看到**游客首页**，不用先登录：介绍、“先试学 10 个词”、“语法基础”、注册后还有什么、登录 / 免费注册按钮。
- **试学 10 个词**：和“今日学习”是同一个页面，认词翻面、发音、例句、拼写都有，忘了的词排到本轮最后再用拼写考一次。选的是 A1 里最常用的词：der、die、das 名词各 2 个，动词 3 个，形容词 1 个，例句有中文翻译的优先。
- 试学做完显示“免费注册，保存进度”。注册或登录后，试学的结果**自动存进学习进度**（提示“试学的 N 个词已保存到你的进度”），明天按记忆曲线复习。已经学过的词不覆盖。
- 试学的 10 个词**功能和登录后一样**：翻面后能打开完整单词卡（复数、变格 / 变位、音标、拼读、词性解释、构词解释、例句和讲解），例句里点到这 10 个词也能查。点到别的词、“加入学习”“加入错题本”这类要账号的操作，弹出注册页。AI 内容只显示已经生成好的，游客不能触发生成。
- **语法基础**游客也能看：速查表和本地出题的练习都能做；按单词书出题的练习（定冠词、动词等）显示“注册后练习”。
- 游客点到要账号的页面（词库、练习、我的等），弹出注册页，上面写着为什么要注册。左上角“‹ 先随便看看”回到刚才的页面，试学做到一半不会从头开始。
- 安装到桌面的整页提示改成**登录后**才自动出现；`?install` 链接仍然一打开就显示。
- 发音默认用在线语音（谷歌），游客也一样；在「我的」页选过设备语音的用户不变。

## 详细设计

| 文件 | 作用 |
|---|---|
| `trial.py` | `GET /api/trial/cards`（不用登录，卡片格式同 `/api/review/today`）；`POST /api/trial/save`（登录后，`{answers: [{word_id, rating, mode}]}`，最多 40 条，只收试学的词，已有进度的词跳过，返回 `saved`）；`allowed_tts()` |
| 单词卡相关接口 | `/api/words/<id>`、`/api/gender_reason`、`/api/parts`、`/api/explain`、`/api/lookup` 没登录时只放行试学的词或例句（`trial.py` 的 `guest_open` / `is_trial_id`，试学词集合缓存 10 分钟），其他返回 401 |
| `vocab.py` | 评分逻辑抽成 `apply_review(db, uid, word_id, rating, mode, now)`，`/api/review/answer` 和试学导入共用 |
| `tts.py` | 游客也能用在线发音；游客触发的新取（缓存里没有的）全站每小时最多 200 次（`GUEST_FETCH_PER_HOUR`，内存里计数），超了返回 429，前端退回设备语音；试学的词不算次数 |
| `static/js/core.js` | `GUEST_PAGES`（welcome / review / grammar / gtopic / gquiz）：`route()` 里游客的 home 换成 welcome，其他页面弹注册；`openLogin(view, why)` 登录页盖在应用上，`loginClose` 只是收起登录页、不重新加载当前页；`saveTrial()` 登录后把本机记录交给服务器；`gateWanted()` 自动显示要求已登录 |
| `static/js/review.js` | `trial = !user` 时卡片来自 `/api/trial/cards`，评分只记在 `trialAnswers`，存本机 `localStorage` 的 `sb_trial`；撤销同样在本机 |
| `static/js/core.js` 的 `api()` | 游客的 POST 请求返回 401（加入学习、错题本、报错等）时弹注册页；`lessons.js` 单词卡查不到（游客点了别的词）也弹注册页 |
| `static/js/grammar.js` | 题库知识点（`t.bank`）对游客隐藏练习范围，开始按钮改成去注册 |
| `static/js/search.js` | `searchLocked()` 游客一律锁住，搜索按钮不显示 |
| `static/index.html` | `welcome` 页、登录页的“先随便看看”和 `loginWhy`、做完页的 `doneSub` |

### 关键取舍

- **服务器不记游客的任何东西**：试学结果只在浏览器里，注册时才上传。不建临时账号，不用清理垃圾数据，也不会被刷出大量用户行。代价是能试的功能有限（方案 A，用户 2026-11-03 选的）。
- 试学导入时间算注册那一刻，不是试学的时候。同一天内注册，差别可以忽略。
- 试学评分后不显示“N 天后复习”的具体天数（那要服务器算），只说“过几天再复习”。
- 本机记录没上传成功（断网等）就留着，下次登录再试。
