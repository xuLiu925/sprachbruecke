# 功能引导

## 功能介绍

帮新用户发现好用、重要的功能，分两种：

1. **第一次登录后的导览（6 步）**：在真实页面上，把要介绍的按钮周围调亮、其他地方调暗，旁边一句说明，点“下一步”切到下一个，随时能“跳过”。依次介绍：开始今天的学习 → 顶栏查词 → 换单词书 → 练习页和错题本 → 装到手机桌面（已经从桌面打开时跳过这步）→ “重新看功能介绍”按钮。
2. **用到时才出现的小提示**：屏幕下方一条蓝色提示，点“知道了”关掉，每条只出现一次：
   - 第一次在今日学习里翻开答案：点“单词卡”能看变格、例句、词性规律和构词
   - 第一次打开情景课：点词查意思、句子旁的按钮能听发音、看讲解
   - 第一次在冠词 / 动词等练习里答错：错的题自动进错题本

「我的」页最下面有“重新看功能介绍”。游客不弹，注册后第一次进来再弹；手机浏览器上先显示安装引导页，关掉以后才开始导览。

## 详细设计

### 涉及的文件

| 文件 | 作用 |
|---|---|
| `guide.py` | `GET /api/guide` 看过哪些、`POST /api/guide {key}` 记一个；存 `user_settings` 的 `guide_seen`（JSON 列表，最多 50 个），不加新表 |
| `static/js/guide.js` | 导览步骤 `TOUR`、`maybeTour()`（`core.js` 的 `boot()` 登录后调用）、`startTour()`、小提示 `tipOnce(key, 文字)` |
| `static/index.html`、`static/app.css` | 遮罩 `#tour`（`#tourHole` 用很大的阴影调暗其他地方）、说明框 `#tourBox`、小提示 `#tip`、「我的」页按钮 `#btnTour` |
| `review.js`、`lessons.js`、`grammar.js` | 调 `tipOnce()` 的地方 |

### 做法

- 看过的记在服务器，换手机、换电脑都不会重复弹。小提示一出现就算看过。
- 导览每一步先 `switchTab()` 切到对应标签页，滚到按钮，再定位“洞”和说明框（下面放得下放下面，否则放上面）。页面内容是异步加载的，按钮会被挤动，所以 250 / 700 / 1500 毫秒各对一次位置，滚动、改窗口大小时也跟着动。
- 目标按钮看不见（比如已经装到桌面，没有安装卡片）就跳过这一步。
- 导览进行中不出小提示，同一时间只显示一条小提示。

### 以后加引导

- 导览：在 `TOUR` 里加一项 `{tab, el, text}`，`el` 是元素 id。
- 小提示：在合适的地方调 `tipOnce("tip_名字", "说明")`，名字只能用小写字母和下划线。
