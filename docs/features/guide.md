# 功能引导

## 功能介绍

帮新用户发现好用、重要的功能，分两种：

1. **第一次登录后的导览（10 步，2026-11-05 改成展示特色功能，同日加入口说明）**：先在「学习」页亮出“全部单词”（单词卡从这里进）→ 自动打开示范词 **der Anruf** 的详情页，在真实内容上依次展示：拼读 → 词性解释和 AI 联想记忆 → AI 构词解释 → 例句讲解（自动打开）→ 亮出底部「练习」标签 → 定冠词练习（说明框里一道示范题，不真的开始练习，不扣次数）→ 「学习」页的“新建我的情景对话” → 亮出底部「我的」标签 → 装到手机桌面（已经从桌面打开时改成介绍“重新看功能介绍”）。说明框顶上有“位置：学习 → 全部单词”这样的标签，告诉用户平时从哪里进这个功能；换到另一块功能前先停一步亮出入口，不直接跳过去。要介绍的地方周围调亮、其他地方调暗，随时能“跳过”。
2. **用到时才出现的小提示**：屏幕下方一条蓝色提示，点“知道了”关掉，每条只出现一次：
   - 第一次在今日学习里翻开答案：点“单词卡”能看变格、例句、词性规律和构词
   - 第一次打开情景课：点词查意思、句子旁的按钮能听发音、看讲解
   - 第一次在冠词 / 动词等练习里答错：错的题自动进错题本
   - 第一次进「学习」页：右上角的放大镜随时能查词

「我的」页最下面有“重新看功能介绍”。游客不弹，注册后第一次进来再弹；手机浏览器上先显示安装引导页，关掉以后才开始导览。

## 详细设计

### 涉及的文件

| 文件 | 作用 |
|---|---|
| `guide.py` | `GET /api/guide` 看过哪些 + 示范词 `showcase {id, german, de}`、`POST /api/guide {key}` 记一个；存 `user_settings` 的 `guide_seen`（JSON 列表，最多 50 个），不加新表。示范词在 `SHOWCASE` |
| `explain.py` | 示范词的例句打开讲解不算 AI 次数（`is_showcase_sentence`） |
| `static/js/guide.js` | 导览步骤 `TOUR`、`maybeTour()`（`core.js` 的 `boot()` 登录后调用）、`startTour()`、小提示 `tipOnce(key, 文字)` |
| `static/index.html`、`static/app.css` | 遮罩 `#tour`（`#tourHole` 用很大的阴影调暗其他地方）、说明框 `#tourBox`、小提示 `#tip`、「我的」页按钮 `#btnTour` |
| `review.js`、`lessons.js`、`grammar.js` | 调 `tipOnce()` 的地方 |

### 做法

- 看过的记在服务器，换手机、换电脑都不会重复弹。小提示一出现就算看过。
- 导览每一步先 `switchTab()` 切到对应标签页，滚到按钮，再定位“洞”和说明框（下面放得下放下面，否则放上面）。页面内容是异步加载的，按钮会被挤动，所以 250 / 700 / 1500 毫秒各对一次位置，滚动、改窗口大小时也跟着动。
- 目标按钮看不见（比如已经装到桌面，没有安装卡片）就跳过这一步。
- 导览进行中不出小提示，同一时间只显示一条小提示。

### 示范词

选 der Anruf：A1 日常词、没有词性规律（才会显示 AI 联想记忆）、构词清楚（an 向 + rufen 喊 → 打电话）、例句 “Sie bekommt viele Anrufe auf ihrem Handy.” 有第四格、复数、双向介词、物主冠词词尾可讲。它的构词、联想记忆、例句讲解在服务器上用 AI 生成后由 Claude 人工改正（原稿把 ihrem 说成“阴性”、把 auf 说成只接第三格、联想记忆只是“蓝色 + 词”），2026-11-05 存进服务器数据库。换示范词时这三样要一起准备并检查；内容缺了的步骤会自动跳过。

### 以后加引导

- 导览：在 `TOUR` 里加一项 `{page, el, where, text}`，`el` 是元素 id（或 `find()` 返回元素，底部标签按钮用 `tabBtn("名字")`），`where` 是位置标签。介绍新的一块功能时，前面先加一步亮出它的入口。
- 小提示：在合适的地方调 `tipOnce("tip_名字", "说明")`，名字只能用小写字母和下划线。
