# 学习路径

## 功能介绍

告诉学习者每一级（A1 → C1）该学什么、学到哪了、下一步做什么。

- **入口**：「今天」页和「学习」页的“学习路径”卡片，上面写着现在在学哪一级、完成了百分之几、下一步做什么。点卡片进入学习路径页。
- **学习路径页**：
  - 顶部可以切换 A1 / A2 / B1 / B2 / C1，现在在学的一级标“现在”，学完的打勾。
  - 大按钮“下一步”：直接进入该做的事。
  - **单词**：这一级单词书学过多少、目标多少。现在的单词书不是这一级时，按钮会先换成这一级的单词书，再进今日学习。
  - **语法**：这一级的语法知识点，按建议的学习顺序排列，标出已完成、最好成绩、还没练。点进去就是原来的知识点页面。
  - **情景课**：这一级的自带情景课，标出学完的。
  - **巩固练习**：用这一级的单词书做句子填空、句子听力、单词听写、整句复习，不计进度。
- **完成标准**：单词书学过 80%；每个语法知识点有一组得分 80% 以上；情景课学完。三部分都完成，这一级就是 100%，“现在”自动移到下一级。
- **下一步怎么选**：单词、语法、情景课三部分里完成比例最低的那部分（比例一样时先语法，再情景课，再单词）。
- B2、C1 暂时只有单词，语法和情景课还在准备中。

知识点归在哪一级、先后顺序，是 Claude 按常见 A1–B1 教材整理的，要对照教材核对。

## 详细设计

- 后端 `learn_path.py`（不叫 `path.py`，避免和常见模块名混淆）：
  - `PATH`：每一级的语法知识点编号，按顺序排列（对应 `grammar-data.js` 的 `GRAMMAR_TOPICS`）。
  - `GET /api/path`：每一级返回 `words {total, learned, goal}`、`grammar [{id, best, done}]`、`lessons [{id, done}]`、`percent`，另外返回 `current`（第一个没到 100% 的级别）和 `book`（当前单词书）。
    - 单词：`word_levels` + `progress`，学过 = progress 里有记录；单词部分的比例 = 学过 ÷ 目标，最多算 1。
    - 情景课：`lessons.lesson_state()` 里学完的课，按课程的 `level` 分级。
    - 完成百分比 = 有内容的几部分的比例取平均。
  - `POST /api/path/grammar` `{items: [[知识点, 得分, 总题数], …]}`：存语法成绩到 `user_settings` 的 `grammar_best`（JSON），每个知识点只留得分率最高的一次。不在 `PATH` 里的知识点、不是整数、得分大于总题数的都跳过。
- 语法成绩以前只存在本机的 `localStorage`（`sb_gbest_知识点`）。现在 `grammar.js` 的 `gDone()` 每组做完调用 `pathSaveGrammar()` 存到服务器。第一次打开学习路径（或今天页）时，`pathSyncLocal()` 把本机以前的成绩一次性传上去，之后记 `sb_gbest_synced` 不再传。
- 前端 `static/js/path.js`：`showPathCard("h" / "l")` 填今天页和学习页的卡片，`onShow.path` 和 `pathRender()` 画学习路径页，`pathNext()` 选下一步，`pathStudyWords()` 先换单词书再进今日学习。
- 没有新表。
