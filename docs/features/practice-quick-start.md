# 练习直接开始

## 功能介绍

以前从「练习」页点定冠词、动词、听写这类练习，要先进知识点页或入口页，选单词书 / 错题本，再点“开始练习”。大多数时候只是想接着练。

现在：

- 「练习」页的**定冠词、不定冠词、否定冠词、物主冠词、现在时变位、完成时、动词搭配、听写、句子听力**点了直接开始，范围用上次选的（没选过就用当前单词书）。
- 答题页顶上有一行“范围：A1 入门 · 换范围”。点“换范围”回到原来的知识点页 / 入口页，选好再开始。
- 知识点的讲解和速查表还在“学习 → 语法”里，学习路径点语法知识点也还是先进知识点页。
- “句子练习”还是先进入口页，因为要选题型（填空、连词成句、中译德、听音填空）。复数练习的入口页有规律速查表，也不变。

## 详细设计

- `grammar.js`：
  - `quickTopic(知识点)`：设 `gTopic`，`gScopeNow = savedScope("gScope")`，直接 `go("gquiz")`。
  - `savedScope(key)`：读上次选的范围，不是现在还有的范围（`okScope`：错题本或 `BOOK_NAMES` 里的单词书）就返回空，后端按当前单词书出题。
  - `scopeLine(元素, 范围, change)`：答题页顶上那一行，`due` 显示“今天到期的”，`wrong` 显示“错题本”，空显示“当前单词书”；`change` 为空就不显示。
  - `scopeChange(页面)`：用 `switchTab()`（`location.replace`）换到入口页，替换掉答题页这条历史。这样选好范围再开始后，按返回键不会回到旧的那一组。
- `index.html`：`#dqScope`、`#gqScope`、`#sqScope` 三行，样式 `.scopeline`。
- 听写、句子练习的答题页在没有指定范围时也用 `savedScope()`，以前存的、现在没有了的范围不会再让接口报“范围无效”。
- 句子练习的答题页只在向服务器要题时显示这一行。情景课、复数、词形练习的题（`sPreset`）不分范围，不显示。
