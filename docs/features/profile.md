# 昵称和通德 ID

## 功能介绍

- **通德 ID**：每个账号一个随机的 8 位数字，注册时生成，以后不变。显示在「我的」页头像旁边，点一下复制。用户联系管理员（比如付了钱没开通会员）时报这个 ID，管理员在成员列表里一搜就找到。不直接用数据库编号，免得从编号看出一共有多少人注册。
- **昵称**：显示用的名字，默认就是注册时的用户名。在「我的」页“账号”里修改，30 天能改一次，可以和别人重名（有 ID 区分）。
- **登录方式不变**：还是用户名或邮箱 + 密码。用户名不能改，「我的」页写明“登录账号：xxx（不能改）”。
- **管理员成员列表**：显示“昵称（用户名）· ID · 已学 · 邮箱 · 会员”，上面有搜索框，能按 ID、用户名、昵称、邮箱筛选。

目前应用里没有排行榜、评论这类别人能看到的地方，昵称只有自己和管理员看得到。头像还是昵称的第一个字，没有做自选头像。

## 详细设计

### 涉及的文件

| 文件 | 作用 |
|---|---|
| `database.py` | `users` 加 `uid`、`nickname`、`nickname_at` 三列（`migrate()` 补列，老账号自动补 ID，`uid` 唯一索引）；`new_uid()` 生成不重复的 8 位数字 |
| `user_profile.py` | 改昵称接口、昵称规则 `check_nickname()`、`display_name()`、`nickname_wait()`。不叫 `profile.py`：Python 自带同名模块 |
| `auth.py` | 注册时写 `uid`；`/api/me` 多返回 `uid / nickname / nickname_wait`；成员列表多 `uid / nickname` |
| `static/js/core.js` | 全局 `userNick`、`userUid`、`nickWait` |
| `static/js/home.js` | 「我的」页 `showProfile()`、改昵称、成员列表搜索 `filterUsers()` |

### 接口

| 方法 路径 | 说明 |
|---|---|
| GET `/api/me` | 多 `uid`（通德 ID）、`nickname`（没改过 = 用户名）、`nickname_wait`（还要等几天，0 = 现在能改） |
| POST `/api/profile/nickname` | `{nickname}`，返回 `{nickname, nickname_wait, next}`；规则不对 400，30 天内改过 429 |

### 昵称规则

- 2–16 个字，只能用汉字、英文字母、数字和 `_ . -`（和新用户名一样，不让用空格、零宽字符冒充别人）
- 不能含“管理员、管理、官方、客服、通德、系统、admin、tongde、system、support”等词（`RESERVED`，不分大小写），也要过敏感词过滤（`content_filter.blocked`）
- 和现在的一样时不算一次修改；第一次改也算，改完 30 天内不能再改（不满一天按一天算）
