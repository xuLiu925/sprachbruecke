# 装到手机桌面（PWA）

## 功能介绍

- 网站可以“安装”到手机桌面：桌面上出现“通德”图标（深蓝底白色拱桥），点开后全屏显示，没有浏览器地址栏，用起来和普通 App 一样。
- 安装提示尽量不用文字（用户 2026-11-06 反馈：一段段步骤没人看）：
  - **一键安装**（安卓 Chrome、Edge）：「今天」页顶部横幅“装到桌面，打开更快 / 安装”，点了直接弹系统安装确认。
  - **苹果 Safari**：同一个横幅，点“安装”后底部冒出气泡指着分享按钮，只写“点 [分享图标] → 添加到主屏幕”（iPad 气泡在右上角）。点哪里都关。
  - **微信 / QQ 等 App 里**：同一个横幅，点了页面变暗，右上角大箭头，“点右上角 [⋮] → 在浏览器打开”（iPhone 是“在 Safari 中打开”）。
  - **其他浏览器**（国产浏览器、iPhone 上的 Chrome 等）：「今天」页不显示横幅；游客首页、「我的」页卡片点“看看怎么装”，底部弹一行“点菜单 [⋮] 或 [≡] → 添加到桌面”（iPhone 上的其他浏览器是“点 [分享] → 添加到主屏幕”，iOS 16.4 以前是“用 Safari 打开本页再装”）。
  - 横幅点 × 后本机 7 天内不再出现；从桌面图标打开时横幅和卡片都不显示。没有“复制链接”了。
- **安装引导整页**：只在打开 `https://tongde.pages.dev/?install` 时显示（发给别人用，电脑上也显示），按上面同样的分法显示按钮 / 一行说明 / 箭头。点“先在网页里用”关掉。
- 连不上服务器时，打开页面显示“连不上服务器 / 重试”，而不是浏览器自带的断网页。
- **不能离线学习**：所有内容和学习记录都在服务器上，断网时什么都做不了。

只有 HTTPS 网址能安装（`tongde.pages.dev` 和 `workers.dev` 都可以）。Tailscale 的 `http://100.x.x.x` 不行。

## 详细设计

| 文件 | 作用 |
|---|---|
| `static/manifest.json` | 名称、图标、`display: standalone`、主题色 `#1f4e78`，`start_url` 和 `scope` 都是 `/` |
| `static/icons/` | `icon-192.png`、`icon-512.png`（圆角）、`maskable-512.png`（满底，图案缩到安全区里，安卓会自己裁成圆形等形状）、`apple-touch-icon.png`（180，满底） |
| `tools/make_icons.py` | 生成上面四个图标，纯 Python，不用 PIL；要改图案就改这个脚本再重跑 |
| `static/sw.js` | Service Worker。只处理打开页面（`navigate`）：取不到时返回内置的断网页。**什么都不缓存**，所以改前端不用改它，也不会出现旧版页面 |
| `app.py` | `/sw.js` 路由：Service Worker 要在网站根目录才能管整个网站；返回 `Cache-Control: no-cache` |
| `static/index.html` | `<link rel="manifest">`、图标、苹果的 `apple-mobile-web-app-*`；「我的」页的 `#installBox` |
| `static/js/core.js` | 注册 Service Worker；记下 `beforeinstallprompt`（`installEvent`）；`installKind()` 分四种：`event` 一键安装 / `ios` Safari / `inapp` 微信 QQ 等 / `other`；`showInstall()` 决定横幅（`#hInstall`，`other` 不显示，`localStorage` 的 `sb_installSnooze` = 到什么时候前不显示）和两张卡片；`doInstall()` 按种类一键安装、`showTip()` 显示气泡 `#iosTip` 或箭头遮罩 `#appTip`、或弹一行面板 `#isheet`；`installLine()` 画那一行（菜单、分享按钮画成小图标）；`installGate()` 整页（`#gate`）只在 `?install` 时显示，等 1.5 秒（`installWaited`）再决定，免得先闪一下 |

为什么不缓存页面：试过把页面和 JS 存下来（断网时从缓存打开），结果打开后是空壳，数字全是“-”，比直接说“连不上”更让人困惑。真要离线学习得把词库和进度存到本机再同步（待办 7b 第 9 条），是另一件事。
