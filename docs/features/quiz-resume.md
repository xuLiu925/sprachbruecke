# 答题中途离开再回来

## 功能介绍

以前在今日学习、冠词练习、听写、句子练习、语法练习里，中途去看单词详情，再按返回，就会重新出一组题，做到一半的进度没了。所以答题页的单词卡里干脆不放“详情”按钮，例句讲解里也不放“替换练习”。

现在：

- 答题时去了别的页面（单词详情、编辑单词、替换练习等），按返回键（手机返回键、左上角“‹ 返回”、浏览器后退都行）回来，**还是原来那一题**，答过的、得分、滚动位置都在。
- 答题页的单词卡又有“详情”了，例句讲解里也有“替换练习”了。
- 从练习入口页、今天页、练习列表重新点进去，照旧出新的一组。

## 详细设计

- `core.js`：
  - `go()` / `switchTab()` 换页时设 `navGo`，`route()` 里 `navGo` 为假（返回键、浏览器前进）就算“回来”。
  - 页面可以注册 `onResume.页面名 = () => 能接着做吗`。回来时先问它，返回 `true` 就不调用 `onShow`。页面的 DOM 一直都在（换页只是藏起来），所以不用重画，只补上标题。
  - `scrollMem` 记着每页离开时的滚动位置，回来时还原。
  - 网址没变的 `go()`（比如已经在这一页）不设 `navGo`，否则下一次返回会被当成重新进入。
- 注册了 `onResume` 的页面：`review`（今日学习，试学和登录后的卡不混）、`drill`（冠词练习，取代以前专用的 `drillToView` 标记）、`dquiz`（听写）、`squiz`（句子练习、复数练习、词形练习、情景课练习）、`gquiz`（语法练习）。条件都是“这一页已经有题”，直接刷新网页时没有题，照常出题。
- 去掉了 `lessons.js` 的 `wsCanLeave()`：单词卡的“详情”和例句讲解里的“替换练习”在所有页面都显示。
- 角色扮演页没有注册（有限时开口的计时器），回来时照旧重新开始。
