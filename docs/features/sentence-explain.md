# 句子讲解

## 功能介绍

例句下面的“📖 讲解”按钮。点开后显示这句话的词形和用法、语序、最值得记住的一点、类似用法，内容由 AI 生成，每句只生成一次，保存后所有人直接看到。

### 在哪里能用

- 情景课的课文
- 单词详情页、底部单词卡、今日学习、冠词练习、听写、句子练习的例句
- 语法基础的**定冠词**、**现在时变位**、**动词搭配**和**完成时③**练习：答题后显示，讲解的是填好答案的整句（动词的短题 `du ___` 不是句子，没有讲解）

### 谁能生成

只有管理员能生成和重新生成。其他人只能看已保存的讲解；这句还没有讲解时显示“这句还没有讲解”。登录用户都能报错。

没有配置 Key 或额度用完时，管理员可以复制提示词到免费 AI，再把回复粘贴回来。

## 详细设计

### 涉及的文件

| 文件 | 内容 |
|---|---|
| `explain.py` | 接口、提示词、检查 AI 的结果；讲解存 `sentence_notes`，用德语原句的哈希做主键 |
| `static/js/explain.js` | 讲解面板 `openExplain()`、`renderNote()`、粘贴备用流程 |
| `static/js/lessons.js` | `exampleExplain()` 在指定元素后面放“讲解”按钮；`exampleInto()` 是例句加讲解的合并写法 |
| `static/js/grammar.js` | 定冠词练习在 `gShowAnswer()` 里调用 `exampleExplain()` |

### 定冠词练习的接入

- 按钮放在词性解释下面，每次答完重建，换题时上一题的讲解自然收起。回看上一题时也能打开。
- 句子用 `gSentence()` 填好答案，所以讲解不会泄露答案，也不会把 `___` 发给 AI。句首的冠词大写后再发。
- 翻译用题目的 `q.zh`。通用句型的翻译是句型配词义的第一个意思，多义词可能不贴切，AI 拿到的中文也一样。
- 用 `gTopic.id === "art-def"` 或 `q.verb` 限定；不定冠词、否定冠词、物主冠词共用这个页面，目前不显示。

### 关键取舍

- **级别：** 练习页和其他练习一样按 B1 讲解，没有按词的级别。
- **没有替换练习按钮：** `gquiz` 在 `wsCanLeave()` 的名单里。跳去替换练习再回来会重新出题，丢掉正在做的这一组。
- **点按钮才调用 AI：** 通用句型配单词书能出几千句，不提前批量生成。

### 已知限制

- AI 内容没有人工核对，语法以教材或老师为准。
- 讲解按句保存，不按题保存：同一句话在不同地方共用一份讲解。
- 还没有全局报错列表。
