# 句子练习

## 功能介绍

用词库里的真实例句练三种题型：

- **句子填空**：看中文，填出句子里缺的词，要写对变位和变格，系统判对错。
- **连词成句**：把打乱的词排成句子。和例句一样算对，不一样时自己对照后选“对 / 不对”。
- **中译德**：看中文写整句德语。和例句一样算对，不一样时自己判断。

入口：底部「练习」→ 句子练习。先选题型，再选练习范围（单词书或这种题型的错题本），点“开始练习”。

- 每组 10 题，按记忆情况选词：先出到期的，再出没练过的（今日学习学过的排前面，然后按词频），最后用还没到期、但最容易忘的补满。
- 答错的句子排到本组最后再练一次。得分只算第一次作答。
- 每种题型各有一本错题本：答错的词自动进去，记牢后自动移出，也能手动加词、移除。统一错题本页里有这三类，没有错题时不显示。
- 练习页“错题本”卡片的“听写·句子”是听写和三种句子题错题的总数。
- 不影响今日学习的复习计划。

## 详细设计

- 后端 `sentences.py`，结构照听写 `dictation.py`。
- 记录按 **词 + 题型** 存：`sent_practice(user_id, word_id, mode, …)`，字段同 `noun_practice`；手动加的词在 `sent_list(user_id, word_id, mode, added_at)`。三种题型练的能力不同（写词形、语序、整句），所以分开记。
- 每次出题时从这个词的例句里随机挑一句能用的，所以同一个词下次可能换一句。
- 评分：对 = 良好（3），错 = 忘了（1），用 `noun_quiz.update_practice()`（2026-11-07 起它多了 `keys` 参数，用来传 `mode` 这种额外的主键列）。同一天再答对不算数；稳定性 ≥ 7 天移出错题本，≥ 21 天算已掌握。
- 前端只上报每组第一次作答；自评的题等用户选了“对 / 不对”才上报。情景课、复数练习、词形练习也用这个答题页（`sPreset`），这些题不记进句子练习。
- 粗筛有例句的词：`words.example` 带换行（有中文翻译），或者 `word_details` 里有 `examples`。能不能出题还要看 `parse_sentence()` / `find_blank()`。没练过的词最多往后看 1500 个，前面的词没有能用的例句时继续往后找。
- 接口：
  - `GET /api/sentences?mode=&scope=&tz=`：出题（免费次数按 `mode` 分开算，不变）
  - `GET /api/sentences/<mode>/books`：各范围的统计（`nouns` = 有例句的词数）
  - `GET /api/sentences/<mode>/words?scope=&page=`：查看一个范围里的词
  - `POST /api/sentences/<mode>/result` `{word_id, ok}`：记一次作答
  - `POST /api/sentences/<mode>/list`、`DELETE /api/sentences/<mode>/list/<id>`：手动加进错题本 / 移出错题本
- 前端 `static/js/sentence.js`：入口页 `#sentence`（`sPickMode` / `sLoadScopes`，题型和范围记在本机 `sMode` / `sScope`），答题页 `#squiz`；单词列表用 `gnouns.js`（`S_LISTS[mode]`）。
