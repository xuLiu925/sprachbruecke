# 单词卡和返回键

## 功能介绍

底部单词卡（点词、搜索结果、答题后的“单词卡”）打开时，按手机返回键：

- 卡片里点过别的词：回到上一张卡（和卡片左上角的“‹ 上一个词”一样）。
- 没有上一张：关掉卡片，留在原来的页面。
- 在搜索层上打开的卡片：先关卡片，再按一次才关搜索。

以前单词卡不在浏览器历史里，按返回键会直接离开整页（答题页上会丢掉正在做的题），或者把搜索层一起关掉。

## 详细设计

- `lessons.js`：
  - `wsShow()`：卡片从关着变成打开时 `history.pushState`，在当前这条历史的 state 上加 `ws: true`（保留搜索的 `search: true`），网址不变。
  - `closeWordSheet()`：用户自己关（×、点空白、Esc）时用，藏起卡片，如果当前历史是 `ws` 就 `history.back()` 退掉。
  - `wsHide()`：只藏起来，不动历史。换页（`hashchange`）、搜索关掉、从卡片进详情页时用。
  - `popstate`：卡片开着、当前历史没有 `ws`（按了返回键）→ 有上一张卡就 `wsBack()` 并补一条 `ws` 历史，没有就 `wsHide()`；卡片关着、当前历史却是 `ws`（从卡片进了详情页，再返回到这一条）→ 自动再退一条，免得要多按一次返回键。
- 从卡片进详情页（“详情”按钮）用 `wsHide()` 而不是 `closeWordSheet()`：`history.back()` 是异步的，会和 `go("view")` 抢，把刚进的详情页又退回去。
- `search.js` 的 `searchSync()` 关搜索时改用 `wsHide()`。
